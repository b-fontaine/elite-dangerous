# PHASE 4 — APPRENTISSAGE PRÈS DE LA BULLE

**Durée : 4-8 sessions · Objectif : apprendre les gestes, pas maximiser**

## 4.1 Keybinds à configurer AVANT (5 min)

- [ ] Répartition des pips SYS / ENG / WEP
- [ ] Boost
- [ ] Deploy / Recall Vessel (Nomad) — via **Role Panel**
- [ ] Heat Sink

## 4.2 Séquence de scan d'un système — checklist de gestes

1. [ ] Sortie de saut → **écarte-toi de l'étoile immédiatement** (surchauffe)
2. [ ] Bascule en **Analysis Mode**
3. [ ] **Maintiens le tir primaire** → « honk » (Discovery Scanner)
4. [ ] **Scoope du carburant** si l'étoile est scoopable (classes K, G, B, F, O, A, M)
5. [ ] Entre en **FSS** → balaie les fréquences → résous chaque corps
6. [ ] Repère les corps affichant **« Biological Signals »** → ce sont tes cibles
7. [ ] Ne **DSS que** : Earth-Like, Water Worlds, Ammonia Worlds, tout terraformable, **et tout corps à signaux bio**
8. [ ] En orbite, tire les sondes jusqu'à **100 %** (vise le limbe pour la face cachée)
9. [ ] Ignore le reste. Saute

> **Erreur fréquente** : tout cartographier. Les corps rocheux/glacés sans bio ne valent pas les 90 secondes.

## 4.3 Séquence exobio avec le Nomad — checklist de gestes

1. [ ] Cible la planète à signaux bio, entre en orbite
2. [ ] **Descends sous 500 m d'altitude** avec le Caspian (ne largue PAS depuis l'orbite : la descente du Nomad est très longue [OFF])
3. [ ] Role Panel → **déploie le Nomad**
4. [ ] Le Caspian suit automatiquement, ou **congédie-le** via le menu
5. [ ] Utilise le **MK II Discovery Scanner du Nomad** pour repérer les signaux bio depuis le cockpit
6. [ ] Pose-toi **lentement, terrain plat**
7. [ ] Sors à pied → **Scan Pulse** (touche 5 par défaut)
   - **Vert** = espèce à scanner / en cours · **Bleu** = déjà fait ou trop proche · **Violet** = autre espèce
8. [ ] Récolte **3 échantillons** de la même espèce, en respectant la **Colony Range**
9. [ ] Rappelle le Caspian, rembarque, système suivant
